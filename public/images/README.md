# Image Assets Directory

Place your new images in this directory or its subdirectories:

- `profile/` - Your hero profile picture (e.g., `profile.png` or `avatar.jpg`)
- `projects/` - Screenshots for your projects (desktop and mobile)
- `certifications/` - Certificates and credentials
- `gallery/` - Campus, events, and leadership milestone photos

### Direct Web Usage
Files placed in `/public/images/` are served at `/images/...` (e.g. `/images/profile/avatar.png`).
